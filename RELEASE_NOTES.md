## Touhou 10 — 1.00a-r6

* 🚀 **Native build, much faster:** the game code now runs as native ARM64 code instead of through a WebAssembly layer. The game's own work per frame is about **60% lower** in the heaviest spell cards, the hardest moments run about **33% faster** when fast-forwarding a replay, and the frame drops in busy boss fights are gone.
* 🔋 **Stock CPU clock:** no more 1785 MHz request, and it is still faster than r5.
* 🕒 **Stays smooth in long sessions:** no slowdown after many restarts, returns to the title and character changes.
* 💾 Same folder, saves, replays and controls.

Just replace `touhou10.nro`.
